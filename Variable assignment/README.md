# Python Exercises Solutions

Each exercise has its **question, objective, expected output, and solution**
inside its own `.py` file.

The code is intentionally kept simple and readable so the files can be
studied and modified one at a time.

## Run an exercise

```bash
py 01_variables.py
```

or:

```bash
python 01_variables.py
```
